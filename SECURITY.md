# Security Policy

Archery Shot Counter Companion is a personal hobby project — an Android app with no
backend server and no user accounts. It talks only to the paired watch app via the
Wear OS Data Layer API. Its attack surface is small, but if you find a real security
issue (not just a bug), please report it responsibly.

## Reporting a vulnerability

Email **vemestael@gmail.com** with details. Please don't open a public issue for anything
that could be exploited before a fix is out.

You can expect an acknowledgement within a few days. This is a solo-maintained hobby
project, so response times may vary, but reports are taken seriously.

## Supported versions

Only the latest release on the
[Releases page](https://github.com/Vemestael/ArcheryShotCounter-android/releases) is supported.
